# Learnify

## An AI-Powered Study Companion

Learnify is a web-based learning application designed to make studying more interactive. It helps students turn study material and topics into structured learning resources such as key points, flashcards, and quizzes, while also providing an AI-powered chatbot for additional assistance.

## Features

- Topic-based learning
- Key-point summaries
- Interactive flashcards
- AI-generated quizzes
- AI-powered chatbot named Pixie
- XP and leaderboard system
- Interactive and animated user interface

Learnify combines AI-generated study resources with interactive elements to create a more engaging revision experience.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Genkit
- Google Gemini API

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

A Google Gemini API key is also required for the AI-powered features.

### Installation

Clone the repository:

    git clone https://github.com/3xclusiv3lyadi/Learnify-v1.git

Navigate to the project directory:

    cd Learnify-v1

Install the dependencies:

    npm install

### Environment Variables

Create a `.env` file in the root directory and add your own Gemini API key:

    GOOGLE_GENAI_API_KEY=your_api_key_here

Never commit the `.env` file or expose your API key publicly.

### Run the Development Server

    npm run dev

Then open:

    http://localhost:3000
