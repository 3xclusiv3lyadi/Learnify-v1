# **App Name**: StudyGenius

## Core Features:

- Persistent Navigation Bar: A persistent bottom navigation bar with icons for Home, Login/Signup, Weekly Leaderboard, Search, and Profile. Provides consistent navigation across all screens.
- AI-Enhanced Home Screen: Home screen featuring AI-generated images of students and subjects (Physics, Chemistry, Computer Science), along with a brief app description.
- Versatile Search Options: Search functionality allowing manual topic input or PDF/PPT uploads.
- AI-Driven Content Summarization: AI powered tool that identifies key concepts, creates internal links to detailed descriptions and diagrams, and generates quizzes and flashcards from uploaded documents or topic searches.
- Comprehensive User Profile: Profile screen displaying profile picture, name, age, gender, description, leaderboard achievements, and points earned.

## Style Guidelines:

- Background: #f5efeb (light and neutral).
- Primary: #0c3b2e (deep green for main elements).
- Secondary: #6d9773 (softer green for accents).
- Support: #bb8a52 (earthy tone for highlights).
- Accent: A warm gold (#FFD700) for achievement badges and interactive elements to give a sense of accomplishment.
- Consistent use of rounded corners for a soft, modern feel.
- Use clear, minimalist icons for the navigation bar and other UI elements.
- Subtle transitions and animations for smooth navigation between screens.
